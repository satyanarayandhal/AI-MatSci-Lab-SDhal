# AI-MatSci-Lab-SDhal
Course portfolio for Artificial Intelligence in Materials Science.
1.  Course Objectives
No.	Course Objective
1	To impart hands-on proficiency in Python-based workflows for acquiring, cleaning, exploring, and featurizing materials data from open scientific databases (Materials Project, AFLOW, NIST-JANAF).
2	To develop the ability to build, optimize, evaluate, and interpret classical machine learning and deep learning models (Ridge, RF, XGB, MLP, CNN, GNN, GPR, Bayesian Optimization) for materials property prediction and design.
3	To cultivate research-grade professional practices — reproducibility, version control, explainability, and scientific communication — through a structured capstone project delivered as a documented GitHub portfolio.

2.  Course Outcomes (COs)
On successful completion of the course, students will be able to:
CO	Domain	Outcome Statement
CO1	ML Fundamentals	Explain the theoretical foundations of supervised, unsupervised, and deep learning as applied to materials property prediction.
CO2	Data & Feature Engineering	Acquire, clean, and explore materials datasets from open databases (Materials Project, AFLOW, NIST-JANAF) and generate, validate, and select compositional and structural feature vectors using CBFV and Matminer.
CO3	Model Building	Build, train, and optimize classical ML (Ridge, RF, XGB) and deep learning (MLP, CNN, GNN) models for materials property regression and classification.
CO4	Evaluation & Advanced Methods	Evaluate models using rigorous cross-validation, interpret predictions with SHAP/LIME, and apply Gaussian Process Regression and Bayesian Optimization to materials design problems.
CO5	Communication & Reproducibility	Document, version-control, and present AI-driven materials research results in reproducible GitHub repositories, reports, and presentations.
